About CrateMind

The CrateMind project is a Python-based intelligent tool that leverages Large Language Models (LLMs) to automatically sort audio files based on their filenames or ID3 tags.

It runs in the terminal, providing the user with a simple and intuitive TUI (Text User Interface). The project is ideal for anyone looking to organize their music library without spending hours on manual sorting.

Key Features:

  • Automatic detection of new audio files in the incoming folder.
  • Metadata extraction (artist, track title).
  • Analysis using an LLM (Gemini Pro) to determine the vibe or genre.
  • Automatic file routing into appropriate folders (e.g., ./Sorted/galaxy trip/).
  • Manual Override classification in case of low LLM confidence.
